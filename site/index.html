Every session starts with a checklist. Nothing spends or reaches the network without your yes.

OmniHarness is a reproducible multi-agent harness for Claude Code, Codex and Hermes: one repository of portable skills all three hosts read, a human-in-the-loop gate, an on-demand adversarial audit loop, an academic layer that never invents a number, and benchmarks that can fail. Open source, MIT.

Contribute

The catalog and the integrations grow by pull request. A row is merged when its URL fetched on the date you name and its numbers are quoted from the source.

  1. Open a PR that adds one row to the right table of docs/catalog/, every column filled.
  2. State the layer it serves and the AGENTS.md routing row it complements, or why none does.
  3. Quote the free-tier numbers with the pricing page URL and the date you read it.
  4. Name the gate entry from harness/settings.json that fires, or "HITL list" when the call has no Bash pattern.
  5. Give the license and any redistribution restriction, and say whether it is security-relevant.
