\section{Reproducing a certified regression}\label{sec:res_longley}

We refit the Longley regression \cite{longley1967} and compare it with the certified values of the NIST Statistical Reference Datasets, which NIST computed in multiple precision \cite{nist-strd-longley}. The data file and the certified-values page are pinned by SHA-256 in the experiment manifest; one command, \texttt{python run.py}, writes the estimates of each method to its own file under \texttt{results/} and the Python, NumPy, BLAS and platform details of the run to \texttt{results/run.json}.

The coefficients come from \texttt{numpy.linalg.lstsq}, an SVD-based solver, and their standard deviations from the same decomposition. The fit gives $\hat\beta_0 = -3482258.6346$ (standard deviation 890420.3836), $\hat\beta_1 = 15.0619$ (standard deviation 84.9149) and $\hat\beta_6 = 1829.1515$ (standard deviation 455.4785), a residual standard deviation of 304.8541, and $R^2 = 0.9955$, matching the certified values at this precision. The comparison script scores every estimate, every standard deviation, the residual standard deviation and $R^2$ by log relative error, and accepts the reproduction only when each score reaches the threshold declared in the manifest; the SVD solution passes. As a control we also solved the normal equations $(X^\top X)^{-1} X^\top y$ in double precision. The control agrees with the certified values to fewer digits and also clears the threshold; it is reported for comparison, not as an acceptance check, and its per-value scores are retained in \texttt{results/check-normal-equations.json}.
